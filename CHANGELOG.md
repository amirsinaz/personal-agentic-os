## 0.3.1 — 2026-08-28

- بخش پیشنهادهای بهینه‌سازی در داشبورد خواناتر و فشرده‌تر شد.
- وضعیت «نیاز به بررسی» و راهنمای آن اضافه شد؛ هیچ تغییری بدون تأیید کاربر اعمال نمی‌شود.
- نمایش شواهد و پیشنهادها در موبایل اصلاح شد.

## 0.3.0 — 2026-08-28

- Added a dashboard notice when a newer version is available.
- Added an optional weekly version check for macOS, Linux, and Windows.
- Kept updates approval-based: the system shows the release first and never installs it automatically.

## 0.2.0 — 2026-08-28

- Added an evidence-backed Personal Agent Registry to the local dashboard.
- Added project-scoped profiles for primary agents and subagents.
- Preserved explicit `unknown` values instead of inferring responsibilities or skills.
- Kept private project data, transcripts, hidden reasoning, and local paths outside public releases.

## 0.1.0 — 2026-08-27

- Published the initial local Obsidian memory, usage, cost, budget, recommendation, and reversible optimization workflow.
