# Changelog

## 0.3.0 — 2026-08-28

- Added a public release manifest and dashboard notification for newer versions.
- Added a privacy-preserving weekly version check for installations that opted into telemetry.
- Added current-version and 30-day active-install reporting to private analytics.
- Added weekly scheduler templates for macOS, Linux, and Windows; installation still requires explicit approval.
- Fixed public-review detection so content changes inside existing file paths create a new Review ID.

## 0.2.0 — 2026-08-28

- Added an evidence-backed Personal Agent Registry to the local dashboard.
- Added project-scoped profiles for primary agents and subagents.
- Preserved explicit `unknown` values instead of inferring responsibilities or skills.
- Added an approval-based review queue for adapting private-system changes to the public project.
- Kept private project data, transcripts, hidden reasoning, and local paths outside public releases.

## 0.1.0 — 2026-08-27

- Published the initial local Obsidian memory, usage, cost, budget, recommendation, and reversible optimization workflow.
