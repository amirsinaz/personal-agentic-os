# Agentic OS project guidance

Before starting:
1. Read `[VAULT_PATH]/00-System/Memory-Policy.md`.
2. Read only this project's `01-Overview.md`, `02-Current-State.md`, `11-Decisions.md`, and relevant workstream notes.
3. Load additional notes only when directly relevant. Never load the whole Vault.

During work:
- Repository code is the source of truth for behavior.
- Approved Vault notes are the source of truth for decisions.
- Never copy credentials, tokens, `.env` values, or raw terminal logs into memory.

After completing work:
- Update `current-state.md` only when state changed.
- Append only confirmed decisions.
- Update open tasks.
- Add a short session summary with result, changed files, decisions, blockers, and next step.
- Do not overwrite a note if its revision changed after reading it.
