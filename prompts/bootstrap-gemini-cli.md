# پرامپت راه‌اندازی با Gemini CLI

```text
هدف: Personal Agenting OS را از `[REPOSITORY_URL]` به‌صورت محلی و Privacy-first برای من راه‌اندازی کن.

محدودیت‌ها:
- ابتدا فقط محیط را بررسی کن.
- قبل از Clone، دانلود، نصب Dependency یا Skill، اجرای Installer، ساخت سرویس دائمی یا نوشتن خارج از پوشه‌ی فعلی اجازه بگیر.
- هیچ Secret، محتوای Vault، نام پروژه، Prompt، مسیر، Token یا Cost را به بیرون ارسال نکن.
- Telemetry پیش‌فرض خاموش است و فقط با رضایت صریح من فعال می‌شود.
- فقط اطلاعاتی را معتبر بدان که از فایل‌ها و خروجی ابزارها قابل تأیید است.

پس از اجازه‌ی من Repository را دریافت کن، فایل `prompts/bootstrap-codex.md` را به‌عنوان مشخصات کامل نصب بخوان و تمام مراحل آن را اجرا کن. هر اشاره به Codex را برای این اجرا Gemini CLI در نظر بگیر و Adapter مربوط به `GEMINI.md` را نصب کن. Setup Wizard رسمی Repository را اجرا کن و منطق نصب را دوباره از روی حدس بازسازی نکن.

اگر Obsidian نصب نیست، مسیر رسمی نصب یا حالت Dashboard-only را ارائه کن. در پایان فقط با تست واقعی Sync و مشاهده‌ی تغییر داده‌ی محلی، راه‌اندازی را کامل اعلام کن. موارد تأییدنشده را صریحاً مشخص کن.
```

🎯 Target: Gemini CLI، 💡 برای استفاده از Setup مشترک، Context فایل `GEMINI.md` و تأیید ابزارمحور نتیجه بهینه شده است.

این Prompt به فایل‌ها و Terminal دسترسی واقعی می‌دهد؛ مسیر Repository و مجوزها را قبل از اجرا بررسی کنید.
